رندر الذكاء الاصطناعي (mnml.ai · LookX · Veras)
=============================================

صفحة الرندر: /designer/ai
من المصمم: زر «رندر AI»

--- mnml.ai (مدمج داخل الموقع) ---

1) سجّل في https://mnml.ai/
2) أنشئ API Key من https://mnmlai.dev/
3) في Windows PowerShell قبل تشغيل السيرفر:

   $env:MNML_API_KEY = "ضع_المفتاح_هنا"
   python 1.py

4) من المصمم → «رندر AI» → تبويب mnml.ai → «تشغيل mnml.ai»

https://www.lookx.ai/
ارفع صورة التصميم من صفحة الرندر AI (تنزيل المصدر).
